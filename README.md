# CarolinaTech

CarolinaTech's concise on-site IT support landing page, built with React, TypeScript, and Vite. Its visual direction uses clean surfaces, clear hierarchy, and blue accents inspired by SAP Horizon.

## Requirements

- Node.js 18+
- npm

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production site is written to `dist/`. Update the React page in `src/App.tsx`
and the shared stylesheet and images in `public/assets/`.

The primary contact actions open WhatsApp, place a call, or start an email to
CarolinaTech.
